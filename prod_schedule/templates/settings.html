📚 Setup Guide
  1. Go to console.cloud.google.com and create a new project (e.g. "Production Schedule").
  2. Enable these two APIs:
    • Google Sheets API
    • Google Drive API
  3. Go to IAM & Admin → Service Accounts, create a service account, and download the JSON key. Upload that JSON file above.
  4. Create a Google Sheet. Add a tab called Inspections. Share the sheet with the service account email (e.g. my-sa@project.iam.gserviceaccount.com) as Editor.
  5. Create a Google Drive folder for inspection attachments. Share it with the same service account email as Editor. Paste the folder ID above.
  6. In the Inspections sheet, add these headers in row 1:
    Job Key, Region, Order #, Item Code, Description, Supplier, Qty Ordered, Inspector, Date, Qty Inspected, Result, Defects, Notes, Files, Submitted At
